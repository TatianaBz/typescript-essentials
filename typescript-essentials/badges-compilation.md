## Reflections

1.Typescript allows you to define the types of processed data, which allows you to correct errors before starting the js algorithm and avoid many errors.

2. The most common data types used by Typescript (string, number, boolean, array) and the corresponding ways of describing these types are considered.

3. In this chapter, we examined the interfaces that define the properties and methods implemented by objects. We realized that the interface is the definition of a "skill" of a data type, but without its practical implementation.

4. The functions were considered as the basic unit of any application. We found out how different types of functions can be described and called in TypeScript and what features of the behavior of functions should be taken into account. implementations.

5. Classes are considered as TypeScript entities. We found out what classes and their objects are, and how classes help group data, create a new instance, and gain access to class members. Class expressions, their declaration and usage are also considered.

6. Generics were considered as generalized types. We learned how they help us describe data that is similar but differs in some characteristics. Generics helps to describe the overall structure, giving the programmer the opportunity to describe a specific organization later.

7. We learned how external libraries work in TypeScript. We found out how they are installed and configured.

8. This section explains the various ways to organize code using namespaces in TypeScript. Concepts such as import, export and validation are considered.
